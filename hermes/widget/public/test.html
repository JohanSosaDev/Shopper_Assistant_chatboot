Página de prueba — Hermes Widget

Esta página simula una página de producto de Patprimo. El widget de chat debería aparecer en la esquina inferior derecha (mismo lugar donde irá en la sandbox SFCC).

Flujos para probar
Flujo A — Consultar estado de pedido
  1. Abre el widget (botón flotante en la esquina inferior derecha).
  2. Escribe Hola → debe pedir consentimiento.
  3. Escribe Si, acepto → debe confirmar y mostrar el menú con las dos capacidades.
  4. Escribe Cual es el estado de mi pedido PP-2026-0001? (o cualquier ID de la tabla) → estado real, ETA y tracking.
Flujo B — Buscar productos por categoría
  1. Abre el widget → Hola → Si, acepto.
  2. Prueba con una categoría concreta: busco jeans, tienen camisas?, quiero un vestido.
  3. Debe responder con top-3 productos del catálogo (nombre, precio, colores, tallas, SKU).
Flujo C — Sub-casos sin contexto (intents refinados)
  1. quiero consultar mi pedido → debe pedir el número (sin asumir que ya lo escribió).
  2. pedido 1234 → debe corregir el formato (PP-YYYY-NNNN).
  3. estoy buscando productos → debe preguntar qué tipo de producto.
  4. ok o hola (después de aceptar) → menú genérico con las dos capacidades.
Flujo D — Edge cases y seguridad
  1. PP-2026-9999 → "No encuentro un pedido…" (anti-enumeration R-ID-2; no expone si existe).
  2. Conversación nueva → Hola → No, no autorizo → consent denied.
  3. gracias o chao en cualquier momento → despedida cordial (closing intent).
